# Catraca

Jogo 16-bit vertical sobre pegar metrô em São Paulo. Roda no navegador, no
celular e no PC. Sem build, sem instalação.

**Jogar:** https://orenanchaves.github.io/catraca-jogo/

**Controles:** `WASD` mover · **clique** (ou `espaço`) agir e confirmar · `X` voltar.
No celular, direcional na tela e toque em qualquer lugar para agir.

---

Este repositório é só a vitrine: contém a versão publicada do jogo e mais nada.
O código-fonte, o documento de design e o histórico ficam em um repositório
privado, e o que aparece aqui é gerado a partir dele.
